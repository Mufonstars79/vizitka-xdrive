# Електронна визитка — xDrive автоинструктор — спецификация

Дата: 2026-10-17

## Цел

Статичен, мобилен-първо сайт на български — електронна визитка за Михаил Гребенаров, автоинструктор във фирма xDrive. Контакти, услуги, галерия, отзиви с модерация през Google Sheets, препоръки на приятели, запазване на контакт (vCard), споделяне.

## Обхват

- Нов, самостоятелен проект (ново GitHub repo `vizitka-xdrive`, акаунт Mufonstars79), статични файлове без build стъпка.

- Деплой: GitHub Pages ("Deploy from branch").
- Без платени услуги.

## Google Sheet + Apps Script

Един Google Sheet, два таба:

### Таб "Reviews"
Колони: `timestamp`, `id`, `name`, `category`, `period` (месец/година), `rating` (1–5), `text`, `consent` (true/false), **`approved`** (чекбокс, по подразбиране невярно).

### Таб "Referrals"
Колони: `timestamp`, `id`, `referrerName`, `friendName`, `friendPhone`, `consent`. Никога не се показва на сайта.

### `apps-script.gs`

- **`doPost(e)`** — очаква JSON тяло, изпратено с `Content-Type: text/plain;charset=utf-8` от клиента (за да се избегне CORS preflight, който Apps Script не поддържа коректно за `application/json`). Стъпки:
  1. Парсва `e.postData.contents` като JSON.
  2. Проверява honeypot полето (`website`) — ако има стойност, тихо връща success без да записва (бот капан).
  3. Проверява `type` ("review" или "referral"), задължителните полета за съответния тип, и дължина на текста (`text` ≤ 500 символа за отзив).
  4. Пише нов ред в съответния таб. За отзив `approved` винаги се задава `false` при създаване.
  5. Връща `{ok: true}` като JSON.
- **`doGet(e)`** — чете таб "Reviews", филтрира само редове с `approved === true`, връща ги като JSON масив, сортиран по `timestamp` низходящо (най-новите първи). Полетата, връщани в JSON: `name, category, period, rating, text, timestamp`. (`id` не е нужен на клиента.)

### Одобряване на отзиви от телефона
През приложението Google Sheets: отваряш таб "Reviews" → чекваш/отчекваш колоната "approved" за съответния ред. Промяната е видима на сайта при следващото зареждане (клиентът вика `doGet` при всяко отваряне на страницата).

## Секции на `index.html`

1. **Hero** — кръгъл аватар (foto-1-portret.jpg), име, "Автоинструктор в xDrive", кратко представяне (2–3 изречения, текст маркиран за редакция от потребителя), лого/име на xDrive като текст-placeholder.
2. **Контакти** — 4 бутона: Обади се (`tel:`), Viber (`viber://chat?number=...`), WhatsApp (`https://wa.me/...`), Имейл (`mailto:`). Всички от `config.js`.
3. **Какво предлагам** — обучение кат. B, допълнителни часове, подготовка за изпит, опреснителни курсове.
4. **Снимки** — галерия с 4-те снимки (виж по-горе).
5. **Запиши се за час** — голям бутон, засега сочи към `tel:`/`viber:` (не към отделния сайт за записване на часове).
6. **Запази контакта** — бутон "Запази контакта", генерира `.vcf` файл в браузъра (Blob + временен `<a download>`) от данните в `config.js` и го сваля.
7. **Отзиви**:
   - Празно състояние, ако няма одобрени отзиви: "Бъди първият, който ще остави отзив."
   - Иначе: среден рейтинг (★ число), брой отзиви, списък с одобрените (най-новите първи).
   - Форма за нов отзив: име/кратко име, категория, месец/година на обучение, оценка (1–5 звезди, кликаеми), текст, чекбокс "Съгласен съм отзивът да бъде публикуван", скрито honeypot поле. При изпращане: POST към Apps Script (`text/plain` трик), съобщение "Благодаря! Отзивът ти чака одобрение."
8. **Препоръчай ме** — бутон, използващ Web Share API (`navigator.share`), ако е наличен; при липса — резервни бутони: копирай линк + директни линкове към Viber/WhatsApp/Facebook с предварително попълнен текст.
9. **Препоръчай приятел** — форма: име на препоръчващия, име на приятел, телефон на приятел, чекбокс "Приятелят е съгласен да бъде потърсен". POST към същия Apps Script endpoint (`type: "referral"`), записва се в таб "Referrals", не се показва никъде публично.
10. **Поверителност** — кратък текст + линк към `privacy.html`.

## `privacy.html`

Кратка страница: какви данни се събират (име/кратко име при отзив, телефон на препоръчан приятел), за какво се ползват (показване на одобрени отзиви; свързване с препоръчани хора), как да поискат изтриване (имейл/телефон за контакт). Изрично: телефоните на препоръчаните хора никога не се показват публично.

## Защита от спам

- Скрито honeypot поле (CSS `display:none`/извън екрана, не `type="hidden"`, за да хващa реални ботове, които попълват всички полета).
- Лимит на дължината на текста на отзива (напр. 500 символа), прилаган и в клиента (`maxlength`), и в Apps Script.
- Проверка за празни задължителни полета — клиент (preventDefault + съобщение) и сървър (Apps Script отказва запис).

## Open Graph и мета тагове

`index.html` включва `og:title`, `og:description`, `og:image` (сочи към `images/og-image.png`, 1200×630), `og:url`, `theme-color`. OG картинката се генерира веднъж (HTML → headless browser screenshot → PNG), с името/марката, в стила на сайта.

## QR код

След публикуване в GitHub Pages и познат финален URL — генерира се `qr-code.png` с офлайн инструмент (npm пакет `qrcode`, еднократно локално), за принтиране на визитки/в колата.

## Извън обхвата (съзнателно пропуснато)

- CAPTCHA или друга усложнена анти-спам защита отвъд honeypot + лимити.
